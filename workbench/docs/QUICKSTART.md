# 在本机开始使用

## 启动

在 Sand Table 仓库根目录执行：

```bash
npm start -- /absolute/path/to/an/already-cloned-repository
```

首次需要联网下载 Sand Table 依赖；目标项目不需要安装依赖，也不会被执行。服务只读取显式绑定的 Git 根目录和支持的跟踪文件。当前只支持已经有 Git 提交的仓库。Python 项目额外使用系统 python3 的隔离模式解析 AST，不导入项目模块；缺少解释器时，文件仍可读取，符号缺口会显示。

终端保持运行，默认自动打开浏览器。如果没有打开，复制终端打印的**完整链接**。链接的 `#session=…` 用于本机认证，界面加载后将其从地址栏移除；同一标签页刷新可继续使用。只打开裸端口地址不会获得会话权限。

页面可以直接浏览，即使尚未连接 AI。通过“连接我的 AI”完成模型侧接入。

## 连接 Codex CLI

点击“连接我的 AI”，复制页面中的安装命令，在本机终端执行。它采用官方 CLI 支持的格式：

```text
codex mcp add sand-table -- <本机 Node 绝对路径> <bridge 参数>
```

页面生成的是本机完整路径，不必自己猜参数。用 `codex mcp list` 检查配置，在新的 Codex 会话中使用 `/mcp` 检查连接。若已有同名的旧配置，先用客户端自己的配置管理移除旧条目，再安装新条目。

接入格式依据 [OpenAI 官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)（2026-10-19 核对）。此处记录的是官方配置方法；本项目自动测试使用独立 MCP 客户端验证协议和共享状态，没有使用用户的模型账号运行付费任务。

也可以展开页面中的通用 JSON 或 Codex TOML，按你的本机客户端配置方式安装。支持标准 stdio MCP 即可读工具；客户端无需显示内嵌 App，也能与浏览器白板一起使用。ChatGPT 浏览器聊天本身不会读取本机配置。

## 第一次提问

先在图中选一个对象或步骤，写一句备注。回到“连接我的 AI”，点击“复制当前选区提问”，再粘贴到客户端对话。它包含当前 boardId，不含会话认证令牌。

Agent 直接用已有 boardId 读取上下文即可，不要为同一问题另建白板。查找更多对象使用 sand_find_objects 分页读取，每页最多 30 项；不要把整个图当成一次模型输入。也可让它用 `sand_list_boards` 查找现有板子。让 Agent 在真实读取前报告任务与工作区；回答中的推断和未验证项应保留。

你仍然在自己的 AI 客户端中输入自然语言。浏览器负责显示、选择和编排，不接管模型运行。修改代码需要使用该客户端的文件工具；当前产品只读，没有产品内的补丁应用功能。

## 生命周期

- 刷新同一标签页：继续当前白板，保留尚在运行的进程内整理。
- “结束白板”：丢弃该板；顶部“重新打开白板”打开新的瞬时会话。
- 停止启动终端／进程：清空全部白板，删除临时连接描述。
- 重新启动：产生新会话与认证令牌，已有 MCP 配置从原来的私有连接文件位置重新发现服务。
- 30 分钟无访问：板到期；打开的界面会定期读取，因此仍会续期。

临时连接文件包含本地地址、随机凭据、PID 和启动时间，不含源码、选区、备注、布局或讲解。它不是事件库。强制杀进程留下的描述文件会在下次确认旧服务不可达后替换。

## 出问题时

| 现象 | 处理 |
|---|---|
| 提示 Node 版本过低 | 安装 Node.js 22.18 或更新版本后重试 |
| 提示仓库没有 HEAD | 对目标仓库完成首次 Git 提交；空仓库尚不支持 |
| “already running” | 使用原来终端里的链接；切换项目时先 Ctrl+C 停止旧进程 |
| 页面要求完整启动链接 | 重新使用终端含 `#session=…` 的链接，不要只复制端口地址 |
| 页面有图，AI 读不到 | 检查客户端配置指向 `local/bridge.ts`；原来的 `server/main.ts` 会启动另一份独立会话 |
| 客户端还看不到新工具 | 确认配置成功后，新建会话或重启客户端 |
| AI 新建了另一块板 | 粘贴页面生成的 prompt，或调用 sand_list_boards 后按 boardId 连接 |
| 源码读取提示 changed | 点“刷新源码”，请 AI 重新读取并更新讲解 |
| 浏览器状态断开 | 重启工作台，使用新的完整启动链接；若 MCP 客户端未自动恢复，重启该 MCP 连接 |
| 目标语言／文件看不到 | 展开索引覆盖说明；首版只支持 Git 跟踪的 JS/TS/Python/Markdown，且有文件和字节上限 |

当前连接状态只说明 MCP 接入进程和工具通信；不把“连接了”当作 AI 正在运行。真实用户客户端、系统权限与模型表现需要在你自己的环境中确认。
