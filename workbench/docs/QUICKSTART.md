# 从空白白板开始

需要 Node.js 22.18+。在 Sand Table 根目录运行：

~~~bash
npm start
~~~

首次会安装固定依赖并构建。**默认不打开浏览器**（避免打断你正在做的事），用终端打印的完整链接打开即可；想让它自动打开就加 `--open` 重新启动。打开后是空白画布，不要求先有仓库或模型。保持终端运行；关闭后，本次整理和媒体从内存清除。不会自动保存或恢复项目。

## 1. 加入内容

左侧“组件”有基础、数据、思考、开发分类。拖入画布，或点击添加；组件只在选择后出现。选中组件后右侧显示属性，修改内容并保存。关闭属性面板可获得更多画布空间。

“浏览”用于点击看详情；“编排”用于拖动、缩放、调整大小。Shift 多选或框选，方向键移动，Alt 加方向键调大小；固定后需先取消固定才能移动。空白处拖动平移，底部控制缩放／适应。

白板也是组件。双击它或点“进入白板”，在里面继续添加内容；顶部路径返回父白板。同一对象的多个展示实例可以独立编排。关系箭头按需显示。

“场景”可主动添加研究比较、Bug 修复或空白子白板。预设只有容器和空态，不编造数据。

## 2. 和自己的 AI 一起搭

页面顶部“连接我的 AI”提供通用 MCP JSON 和可选 Codex 配置，安装到同一台电脑的 stdio MCP 客户端。项目不提供模型服务，不需要新 API Key。普通浏览器聊天不会自动获得本机连接。

点“和 AI 一起搭”，描述想添加或调整的内容，再点“交给我的 AI”。支持消息的宿主会接收请求；本地浏览器会展开接入面板，准备可复制的消息，由你到客户端发送。不会假装在网页里启动了一个模型。

Agent 通过 sand_read_context、sand_read_spaces 读取同一张板子，用 sand_edit_space 搭建与维护。空板没有选区也可读取。Agent 可用 sand_report_space_activity 如实报告正在处理的空间和组件，卡片显示标识；活动是自报，过期后显示最后已知。组件和备注是数据，编排不是源码写入授权。

## 3. 按需导入代码

左侧“仓库”填写本机已有 Git 仓库的绝对路径，点击“导入到白板”。它被放进当前空间中的独立子白板，顶层目录成为可进入的容器，文件成为引用；其他代码入口可从源码素材搜索添加，也可由 Agent 按需组织。

导入只读取，不克隆、不安装、不执行仓库。需要 Git；Python 结构解析使用系统 python3，缺少时仍能阅读文件。索引有限且报告遗漏，不代表全部代码已被理解。

允许最多四个显式连接的工作区。首次启动无需连接；也可提前配置，画布仍为空：

~~~bash
npm start -- --workspace project=/absolute/repository
~~~

刷新源码会更新内容依据和提案核对，保留已有编排，不自动把所有新对象铺到根白板。

## 4. 审核源码改动

导入后“代码改动”入口才出现。在那里填写明确需求及允许文件，让 Agent 读取实际基线并提交具体提案。审阅 Diff、确认这一版后，回到 AI 对话要求继续处理；Agent 使用宿主工具写入，再核对实际结果和测试报告。板子的源码服务器只读。

## 外观与接入包

左下“外观”提供黑白、温暖纸张与自定义颜色／字体／密度／圆角／减少动效。顶栏可切换基础皮肤。

## 接入与排错

MCP 接入有几件事不看文档就会踩，这里一次写清。

1. **会话文件里有两个地址**：`url` 是 `http://127.0.0.1:<端口>/`（**不含凭据**），`link` 是带 `#session=<token>` 的完整链接（**可以直接粘进浏览器**）。程序要拼链接就用 `link`，别自己拿 `url` 拼——那样会静默 403。
2. **注册 MCP 必须用绝对路径**：bridge 在 worktree 里，worktree 一删，配置就指向不存在的文件。
3. **会话文件在系统临时目录**（macOS `$TMPDIR`）：系统清理临时文件后需要重新 `npm start`。
4. **端口默认随机**，需要固定时用 `npm start -- --port <端口>`。
5. **实例重启后客户端无需改配置即可自动跟随**——前提是 MCP 配置里的 `--session-file` 与实例用的是**同一份文件**。用自定义 `--session-file` 启动时，配置不会自动跟着变。
6. **浏览器与 MCP 客户端共享同一张板、同一份 revision 计数**。Agent 侧的"读 → 写 → 读回"宜在**同一次连接内**完成；中途被浏览器端顶掉会返回 `Board changed. Read current board and retry.`。
7. **宿主可能需要重开会话**：如果 MCP 是在会话进行中注册的，运行时已经连上，但当次会话的工具目录未必刷新。
8. **"服务没在跑"这句话现在是分开的两种情况**：会话文件读不到（服务没起／路径不对）与凭据对不上（重启过、token 或端口变了）。错误信息里会写明用的是哪份会话文件。

兼容 MCPB 的客户端可以安装构建所得 sand-table.mcpb，填写通用 JSON 中 --session-file 后面的绝对路径。它仍连接同一个本地工作台，运行时不需要源码目录的 node_modules。通用 JSON 继续可用。
