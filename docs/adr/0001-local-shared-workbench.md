# ADR 0001：本地浏览器与 MCP 客户端共享白板

状态：实现。依据：D15、D16、D22–D24，以及用户要求继续开发直到能直接使用。

MCP App 在不同客户端中的呈现支持各异。为提供可运行的入口，增加本地浏览器呈现同一个 MCP App，同时保留原生客户端内嵌资源。用户在已有客户端中对话，浏览器负责空间交互；不建立第二套 Agent 或模型调用系统。

根启动器启动一份 stdio MCP 服务与本地 HTTP 外壳。浏览器 AppBridge 和本机 MCP bridge 转发到同一服务，避免“浏览器有一块板，Agent 另开一块板”。新增列举与按 ID 连接会话的工具。各客户端仍共享当前选区与整理，修订冲突由原模型处理。

服务仅监听 loopback。自动生成的配置不含固定密钥；bridge 从受保护临时描述发现当前地址与凭据。该描述只含连接信息，退出删除，不保存源码或任何白板内容。浏览器凭据从链接片段载入，公开页面不提供凭据。此改动没有引入白板数据库、历史或 Agent 运行时。

本机 SDK 客户端与浏览器完整链路已有自动证据。具体商业客户端、用户模型账号与真人体验仍须分开验收。该入口使产品可以先使用，不等于所有规划阶段通过。
