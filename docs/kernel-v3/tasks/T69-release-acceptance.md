## 为什么

自动测试证明契约成立，不证明好用。每次发布前由真人按固定任务走一遍，结果和自动测试分开记录，互不顶替。

## 固定范围

记录：本次发布的提交号、包含的任务卡、已知未完成项、设备与浏览器、AI 客户端。

## 真人任务（每项记“完成 / 卡住在哪一步 / 用时”，卡住时附截图）

1. **无 Git、无 AI**：新建工作空间，从空白开始整理一份读书笔记（至少 10 个组件、2 块嵌套白板、5 条关系），关掉再打开，内容都在。
2. **导入旧作品**：用一份 v2 的 `workspace.json` 启动，自动导入，原来的组件、关系、附件都在。
3. **小说**：建 3 个人物、3 个章节、5 个事件，用参与关系和交叉情境（T60 之后）整理“某人物 × 某章节”。
4. **科研**：导入一篇 PDF，引用其中 3 页做证据，连到一个假设上；替换 PDF 后能看出引用失效。
5. **代码理解**：导入一个外部小仓库，找到一条功能路径，让 AI 写一段讲解并挂到对应代码对象上。
6. **AI 协作**：在你常用的 AI 客户端里连接 Sand Table，让 AI 读你当前选中的内容、新建两个组件、撤销其中一个。
7. **导出分享**：导出工作空间再导入到新工作空间；导出一块白板为图片（T56 之后）。

## 主观记录

连续使用 30 分钟后：哪里让你停下来想“该点哪里”、哪里眼睛累、哪里找不到东西、哪里被打断。照实写。
