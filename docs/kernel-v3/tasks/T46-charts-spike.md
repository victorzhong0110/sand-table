## 要回答的问题

为柱状图、折线图、散点图（第一阶段），以及悬停、图例、范围选择、高亮联动（第二阶段）选一个图表库。候选：Vega-Lite、ECharts、Observable Plot；可以提出别的。

逐项实测：

1. 三种基础图在 300×200 的卡片里是否清晰；在 2000 个数据点时是否流畅。
2. 悬停提示、图例开关、框选范围、外部传入“高亮这些行”的能力。
3. 黑白、暖纸两套主题能否用 CSS 变量或配置统一配色。
4. 缺失值（`null`）的显示：断开、跳过，**不能当成 0**。
5. gzip 体积，以及按 T41 的规则能否按需加载。
6. 许可证。

**重要约束**：图表配置存在我们自己的格式里（字段映射、图表种类、聚合方式），不直接存某个库的配置，以后换库不需要迁移数据。验证里要给出“我们的格式 → 该库配置”的转换函数原型。
