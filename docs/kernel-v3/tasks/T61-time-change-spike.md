## 要回答的问题

用小说场景回答，但设计必须是通用的（领域词只出现在小说包里）：

1. **状态变化**：林舟在第三章是学生、第七章成了老师的对手。怎么记录“某对象在某个时间点或事件之后处于某种状态”？候选：状态记录对象（引用主体对象 + 时间锚点：事件、章节或时间排序值），带“已确认 / 推测”和依据。
2. **时间维度**：故事发生时间、叙述顺序、编辑历史三者如何分开？一章跨多个时期、一次变化涉及多章，怎么表达？
3. **分支**：备选剧情（“如果林舟没有离开”）怎么表达？分支里的内容如何与主线共享未改变的部分、又不污染主线？
4. **观察者情境**：“老师在第五章时以为林舟已经离开”——某个参与者在某时的认知，怎么表达，怎么和事实区分？
5. **查询**：“第五章时林舟的状态”“老师在第五章知道什么”能否用现有关系查询表达？需要内核加什么查询能力？代价是什么？
6. **AI 维护**：AI 发现前后矛盾时（第三章说林舟 17 岁、第九章说 15 岁），怎么提交为“建议”而不是直接改正式设定？
